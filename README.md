# Road to 5 · AP Study Site

AI-written AP lessons for every College Board unit and topic, adapted to how each student learns.

- **24 AP courses · 173 units · 1,448 topics**, following the College Board Course and Exam Descriptions (`data/courses.js`).
- **Lessons generated by Claude** for the exact topic, written for the student's knowledge level and learning style.
- **Formulas in LaTeX** (KaTeX), each followed immediately by a plain-language explanation and a symbol key, with an **Explain further** button that streams a short deeper explanation.
- **Knowledge check** the first time a student opens a course ("How much do you already know?").
- **Supabase-ready accounts**: progress lives in the browser today and syncs to Supabase once you add two keys.

## Run it locally

```bash
npm install
cp .env.example .env        # add ANTHROPIC_API_KEY
npm run dev                 # http://localhost:3000
```

No API key yet? `npm run dev:mock` serves a built-in demo lesson for every topic so you can click through the whole site.

## Deploy (Vercel)

1. Push this folder to a GitHub repo and import it in Vercel (no framework preset, no build command).
2. Add `ANTHROPIC_API_KEY` under **Project Settings → Environment Variables**.
3. Deploy. The static site is served from the root, and `api/lesson.js` and `api/explain.js` become serverless functions (see `vercel.json` for timeouts).

Any host that serves static files and runs Node functions works. `server.js` shows the full contract: static files and two POST routes that stream NDJSON.

> **Cost note:** the API routes are public and spend your Anthropic credits. Before sharing widely, add rate limiting (for example Vercel Firewall rules or Upstash) or require sign-in for `/api/*` once Supabase is on.

## How lessons adapt (the learning-style system)

Students shape their lessons four ways:

| Where | What they do | What changes |
|---|---|---|
| First visit to a course | "How much do you know?" (Brand new → Exam review), units they're confident in, what they struggle with | Starting level for every lesson in that course |
| First visit ever | Pick a style (Step by step, Examples first, Visual, Stories & analogies, Big picture) and length | Global profile |
| **Rewrite it** bar on every lesson | One tap: Simpler, Challenge me, More examples, Shorter, More visual, Explain differently | Instantly regenerates the lesson, then offers "Make it my default" |
| End of every lesson | Too hard / Just right / Too easy | Nudges difficulty for that course (−2…+2) |
| **My learning style** page | Full controls, a 3-question style quiz, interests (used for analogies), free-text notes to the tutor | Global profile |

All of it lives in `js/learning.js` (client) and `api/_lib/profile.js` + `api/_lib/prompts.js` (server, where every field is validated before it reaches the prompt).

## Turning on sign-in (Supabase)

1. Create a Supabase project.
2. In **SQL Editor**, run `supabase/schema.sql` (tables + row-level security).
3. In **Authentication → Providers**, enable Email (magic link) and optionally Google. Add your site URL to the redirect allow-list.
4. Paste the project URL and anon key into `js/config.js`.

That's it. The Sign in button switches from "coming soon" to real sign-in, and `js/store.js` merges local progress into the account on first sign-in, then keeps it synced.

## Project layout

```

css/styles.css        All styles, light/dark themes, animations

api/lesson.js         POST /api/lesson → streams a structured lesson
api/explain.js        POST /api/explain → streams an "explain further" note
api/_lib/             Prompts, JSON schema, validation, Claude client, demo data
supabase/schema.sql   Tables + row-level security for accounts
server.js             Local dev server (mirrors Vercel)
```

## Configuration

| Env var | Default | Purpose |
|---|---|---|
| `ANTHROPIC_API_KEY` | (none) | Required for real lessons |
| `LESSON_MODEL` / `EXPLAIN_MODEL` | `claude-opus-5` | Model per route |
| `LESSON_EFFORT` / `EXPLAIN_EFFORT` | `medium` / `low` | Thinking effort; lower is faster and cheaper |
| `MOCK_AI` | unset | `1` serves demo lessons with no API calls |

Lessons are cached in the browser (up to 40) keyed by topic and learning profile, so revisiting a lesson is instant and free.

## Keeping the curriculum current

The College Board revises CEDs periodically (for example Physics 1/2/C and Psychology in 2024–25, and CSA in 2025–26). Edit `data/courses.js` and run `npm run check` to validate ids and structure. The English Language and Literature units are skill-based, so their topics are organized by the CED's skill focus rather than content.
